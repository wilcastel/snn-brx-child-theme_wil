# Documentación del Tema SNN-BRX-WIL

Este directorio contiene documentación viva del proyecto para facilitar la comprensión, mantenimiento y evolución del tema hijo.

## Estructura
- `architecture.md`: visión general de la arquitectura y módulos.
- `conventions.md`: convenciones de código, hooks y estándares.
- `testing.md`: guía de pruebas y estrategia de calidad.
- `roadmap.md`: líneas de acción y prioridades (alta-nivel).

## Principios
- Fuente única de verdad: lo que se acuerda, se documenta aquí.
- Breve y accionable: priorizar ejemplos y decisiones.
- Mantener sincronía con el código (actualiza cuando edites).

## Cómo contribuir a la docs
1. Crea/edita archivos en `docs/` con cambios atómicos.
2. Incluye contexto: objetivo, decisión, impacto.
3. Usa español y el dominio de texto `snn` en referencias de código.
